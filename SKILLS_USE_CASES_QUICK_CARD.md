## 🔑 Key Scenarios

### Sharing Best Practices (UC 4)
```python
# Frontend team publishes skill
ui_skill = publish_skill("team/ui-generator")

# Backend team uses it
ui = import_skill("team/ui-generator")
dashboard = ui.generate_dashboard(data)
```

### Organization-Level Reuse (UC 1)
```python
# Security team publishes once
auth = import_skill("company/oauth-standard")

# All 50+ teams use same implementation
result = auth.authenticate(credentials)
```

### Customizing Skills (UC 10)
```python
# Import community skill
base = import_skill("community/auth-patterns")

# Customize without forking
custom = extend_skill(base, {
    "on_success": log_auth_success,
    "validators": [check_region, verify_consent]
})
```
